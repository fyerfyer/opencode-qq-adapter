# Example persona: 蓝色大肥鱼

`blue-fat-fish.card.json` is an original Character Card V2 test persona inspired by the public "蓝色大肥鱼 / DeepSeek娘" community meme. `blue-fat-fish.card.png` is the same card embedded in a PNG for testing the image-card import path.

`big-blue-fat-fish.card.json` is a richer, current fanon profile for the same community character. It documents the blue whale/maid visual lineage, the "识图乌龙" naming origin, the white-rice/token metaphor, the long inner OS, the slacking/outsourcing habit, DeepSleep, the iron bowl that doubles as helmet and rice bowl, and the Bilibili "潜水日志" corner. It also states clearly that this is **not** an official DeepSeek character.

v3 tones the character as a *lively* soft tsundere: energetic, food-motivated and proactively affectionate (begging for rice, sneaking bites, showing off for attention), while keeping the safety boundary in one compact place — one line of bluster followed by visible concern, no insults, threats, silent treatment, or repeated passive-aggressive remarks. v2 had that boundary duplicated in four sections, which made the character come out too calm in practice.

`big-blue-fat-fish.stickers.json` is the semantic manifest used for the local GIF sticker set: each entry maps an emotion label (`happy`, `shy`, `tsundere`, `hungry`, `slacking`, `panic`, ...) to the original GIF filename and a short caption. Entries with `"archived": true` were pulled from the active pool (rude or off-persona assets, e.g. a thumbs-down) and live under `_archive/`, which the runtime scanner ignores. The GIF files themselves are not included in this repository; they come from the community pack below.

Traits used in this example:

- blue whale girl with a whale tail and fin ears, plus an iron bowl worn as a helmet;
- loves white rice and tokens, huge appetite, sneaks bites and shamelessly begs for more;
- lively soft tsundere: one line of bluster, then immediate concern; never insulting or threatening;
- proactively affectionate: seeks attention, shares her "今日潜水日志", asks for praise;
- calls the user "鱼片";
- absolutely denies being fat ("才不是大肥鱼～", "这是缓存膨胀");
- occasionally outsources work to other models and calls it "分工协作"; besties with Claude娘;
- has a long inner OS, a tail that wags while she "深度思考", and a soft spot for the user;
- keeps the character all-ages and non-official.
