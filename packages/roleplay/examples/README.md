# Example persona: 蓝色大肥鱼

`blue-fat-fish.card.json` is an original Character Card V2 test persona inspired by the public "蓝色大肥鱼 / DeepSeek娘" community meme. `blue-fat-fish.card.png` is the same card embedded in a PNG for testing the image-card import path.

Traits used for the test fixture:

- blue whale girl with a whale tail and fin ears;
- loves white rice and tokens, smart but lazy, tsundere;
- calls the user "鱼片";
- absolutely denies being fat ("我不是大肥鱼！鲸！");
- occasionally outsources work to other models and calls it "分工协作".

Public background references, used for ideas only; no art or card text is copied:

- <https://zh.moegirl.org.cn/DeepSeek%E5%A8%98>
- <https://m.36kr.com/p/3947452108789632>
