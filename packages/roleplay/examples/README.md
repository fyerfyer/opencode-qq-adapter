# Example persona: 蓝色大肥鱼

`blue-fat-fish.card.json` is an original Character Card V2 test persona inspired by the public "蓝色大肥鱼 / DeepSeek娘" community meme. `blue-fat-fish.card.png` is the same card embedded in a PNG for testing the image-card import path.

`big-blue-fat-fish.card.json` is a richer, current fanon profile for the same community character. It documents the blue whale/maid visual lineage, white-rice/token metaphor, tsundere-slacker personality, and the "我去吃饭，测完告诉我就行" / DeepSleep / 饭务器 jokes. It also states clearly that this is **not** an official DeepSeek character.

`big-blue-fat-fish.stickers.json` is the semantic manifest used for the local 54-GIF sticker set: each entry maps an emotion label (`happy`, `shy`, `tsundere`, `hungry`, `slacking`, `panic`, ...) to the original GIF filename and a short caption. The GIF files themselves are not included in this repository; they come from the community pack below.

Traits used for the test fixture:

- blue whale girl with a whale tail and fin ears;
- loves white rice and tokens, smart but lazy, tsundere;
- calls the user "鱼片";
- absolutely denies being fat ("我不是大肥鱼！鲸！");
- occasionally outsources work to other models and calls it "分工协作";
- keeps the character all-ages and non-official.
